# CUTOUT STUDIO

CUTOUT STUDIO is an Android app concept for transforming a front camera punch-hole into a premium visual effect zone. This repository contains a working Android MVP foundation for the app architecture, UI shell, cutout detection model, animated overlay renderer, and effect configuration system.

## Features included
- Android project scaffold in Kotlin + Jetpack Compose
- Dark premium UI
- Cutout geometry detection model
- Animated cutout overlay renderer
- Effect presets and visual configuration
- Notification and unlock profile UI placeholders
- App structure ready for expansion into a production Android project

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- AndroidX
- View-based custom drawing for camera cutout effects

## Structure
- app/
  - MainActivity
  - UI screens and effect preview
  - custom overlay renderer
  - core models and detectors

## Quick start
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on a device or emulator.

## Notes
This repository is a clean, functional foundation for the CUTOUT STUDIO concept. It is designed for extension into a robust production implementation with more advanced notification listeners, OEM cutout handling, and profile persistence.
